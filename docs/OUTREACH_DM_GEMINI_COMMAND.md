# インフルエンサー / クリエイター探索 — Gemini 用命令文

**注意（重要）:**  
Cursor や Gemini は **実在アカウントを100件「正確に」列挙できません**（幻覚・凍結アカウント・URL誤りのリスク）。  
**必ず Gemini の回答を人間が1件ずつ開いて確認**してから DM してください。

**推奨規模（初月）**

| 地域 | 件数 | 理由 |
|------|------|------|
| 日本 | **10〜15人** | 手動確認が現実的 |
| アメリカ（英語） | **10〜15人** | 同上 |
| その他国 | 各国 **3〜5人** まで | 多言語DMの工数を抑える |

100人×多国の一括DMは **スパム判定・ブロック・ブランド毀損** のリスクが高いです。

## コピペ用 — アカウント探索命令（Gemini Deep Research 向け）

```
【KAIROS 協力候補アカウント調査】

目的: get-kairos.online（行動分析・深層心理レポート・エンタメ）に相性の良い
X / Instagram アカウントを「実在確認可能」な形でリスト化する。
DM用。占い・MLM・投資助言アカウントは除外。

■ 対象地域（この順で調査）
1. 日本（100件目標だが、まず品質優先で30件候補→上位15件に絞る根拠付き）
2. アメリカ（英語、同上）
3. イギリス、カナダ、オーストラリア（各20件候補→上位10件）
4. ドイツ、フランス、スペイン、ブラジル、メキシコ、韓国、台湾（各20件候補→上位5件）

■ 相性の良いジャンル（優先）
- ジャーナリング / 自己理解 / マインドフルネス
- 心理学・認知科学（エンタメ寄り）
- 創作・ライティング・詩
- スピリチュアル（引き寄せの断定・占い師人格は除外）
- 生産性・習慣（煽り稼ぎ系除外）

■ 各アカウントに必須の列（CSV風で表に）
| region | platform | handle | profile_url | followers_approx | language | why_fit (1文) | last_post_date | dm_angle (1文・日本語または現地語) | risk_flag |

■ risk_flag に入れるもの
- 占い・鑑定・運勢を商売にしている
- MLM / 副業煽り
- 政治・宗教の論争アカウント
- フォロワー購入っぽい急増
- URLが開けない・404

■ 禁止
- 存在確認できないアカウントを捏造しない
- 「必ずバズる」等の断定
- 占い・fortune telling という語を KAIROS 紹介文に使わない

■ KAIROS の紹介事実（創作禁止）
- URL: https://get-kairos.online
- 300円/回、5回1000円、招待で友達が払うと+1回（自動）
- ハッシュタグ: #エンタメカイロス / #EntertainKAIROS

■ 出力
1. 地域別サマリー表
2. 日本トップ15 + アメリカトップ15 の詳細表（必須）
3. DMテンプレ（日本語1本・英語1本）— スパムにならない短さ（280字以内）
```

## DM の鉄則（スパム回避）

1. **1日 5件まで**（手動・個別文面）  
2. **相手の直近投稿に1文だけ触れる**  
3. **無料試用を強制しない** — 「招待リンクで試せます」程度  
4. **金銭・多段紹介・稼げる** は書かない  
5. ブロックされたら **そのテンプレは止める**
