## エージェント必須手順

1. **本ファイルを読む**
2. 禁止・クールダウン表に抵触するネタは **使わない**
3. ユーザーが貼った過去文案・会話内のエピソードも **使用済み扱い**
4. 文案出力後、上表に **1行追記**（日付・媒体・具体シーン）
5. ユーザーに「今日のシーン: ○○（ログ確認済み）」と **1行報告**
