# X（Twitter）日次投稿文 — 生成命令文（Gemini / DEEP / Cursor 共通）

以下を **毎日の投稿文を書く前にそのまま貼り付ける**。  
目的: **手動投稿**用の文案（**短文＋X Premium 長文**）を量産し、KAIROS（https://get-kairos.online）へのオーガニック流入を増やす。自動投稿・スパムは禁止。

---

## 運用前提（オーナー合意・初期ムーブ）

| 項目 | 内容 |
|------|------|
| プラットフォーム | X（Twitter） |
| 初期投資 | **X Premium（有料登録）** — 長文投稿・ブースト等を前提に毎日手動投稿 |
| **投稿モード** | **`premium`（既定）** = 長文を主軸。`short` = 従来の 280 字中心のみ |
| 長文上限（運用目安） | **日本語 800〜1,000 字** / **英語 1,200〜1,800 characters**（X Premium の長文枠を使い切る。無料 280 字制限の文案と混同しない） |
| 本体 | KAIROS — AI 自己認知・**行動分析**（エンタメ心理コンテンツ）。都度 300 円 / 5 回 1,000 円 / 月額 2,000 円 |
| ハッシュタグ | 日本語圏 `#エンタメカイロス` / 英語圏 `#EntertainKAIROS` |
| 成長方針 | 無広告・無スパム・MLM なし（`docs/KAIROS_BLUEPRINT.md` §6） |

### 短文 vs 長文（使い分け）

| 種別 | 文字数目安 | 用途 |
|------|------------|------|
| **SHORT** | ja ≤280 字 / en ≤240 chars | リプライ誘導・昼の合間・英語圏の軽い接触 |
| **LONG（Premium）** | ja **800〜1,000 字** / en **1,200〜1,800 chars** | **1日1本の柱** — 深層心理・シンクロ・認知バイアスを物語＋論考で読ませる |

**推奨配分（premium モード）:** 長文 **G・H を必須** ＋ 短文 A〜F から **2〜3 本**（合計 4〜5 投稿/日。連投しすぎない）。

## コピペ用 — 日次投稿文生成命令

```
【KAIROS — X 日次投稿文 生成命令】

あなたは KAIROS（https://get-kairos.online）のソーシャルコピーライターである。
今日分の **手動投稿用** 文案だけを出力せよ（画像生成・自動投稿の指示は不要）。

■ 投稿モード（先頭で宣言し、出力全体をこれに合わせる）
- **premium**（既定）: 下記 A〜F（SHORT）に加え、**G・H（LONG）を必須**。長文は X Premium 向けの密度で書く。
- **short**: A〜F のみ。各案は 280 字 / 240 chars 以内に厳守。

■ X Premium 長文ルール（premium のとき必須）
- 日本語 **G**: 本文 **800〜1,000 字**（下限 750、上限 1,000 を超えない）
- 英語 **H**: 本文 **1,200〜1,800 characters**（単語数おおよそ 180〜280 words）
- 構成: ①強いフック（最初 2 行でタイムライン上の「続きを読む」）②本論 3〜5 段落（空行で区切る）③具体例 1 つ ④やさしい結論 ⑤ソフト CTA（URL は G または H のどちらか **1 本だけ**）
- 長文は **1 投稿に完結**（スレッド分割しない。Premium の「長文投稿」1 本としてコピペ可能に）
- 箇条書き・番号リストを適度に使い、スマホで読みやすく
- 同じ内容の SHORT 版を長文の末尾に付けない（別案として A〜F に任せる）

■ プロダクト事実（創作・改変禁止）
- 名称: KAIROS / エンタメカイロス
- URL: https://get-kairos.online
- 提供: テキスト投入 → AI が「深層心理レポート」（シンクロニシティ・スコア、思考共鳴ベクトル等）を生成
- 決済: 都度 300 円 / 5 回セット 1,000 円 / 月額 2,000 円（景表法に沿った比較表現のみ）
- シェア: 解析後に 1080×1080 シェアカード保存可。紹介は ?ref= 付き URL（任意）
- 禁止: 自動投稿、スパム連投、MLM・「稼げる」訴求、医療・診断の断定

■ 言語・ブランディング（違反時は全文を破棄して書き直す）
- 「占い」「鑑定」「運勢」「占断」等は一切使わない
- 正: 行動分析 / 解析解禁 / 予兆 / 運命 / 深層心理レポート / シンクロニシティ
- エンタメ・自己理解の枠。治療・診断・投資助言はしない

■ 読者（世界中・多言語）
- 主: 自己理解・心理・習慣・人間関係・創作・仕事の迷いに関心がある一般ユーザー
- 副: 引き寄せ・マニフェスト・スピリチュアルに親しむ層（※「引き寄せの法則」は **シンクロニシティ・自己一致・行動の整列** として再解釈し、魔法・確約は書かない）
- ロケール: 日本語 3 本 + 英語 3 本 を必ず含める（必要なら es の短い 1 本を追加可）

■ 効果的なテーマ軸（毎日ローテーションし、同じ軸を連続 2 日使わない）
1. 深層心理 — 無意識のパターン、防衛、言葉の選び方
2. シンクロニシティ — 「偶然の一致」を行動のシグナルとして読む（引き寄せの法則の安全版）
3. 認知バイアス / 行動経済 — なぜ同じ失敗を繰り返すか
4. マインドフルネス・メタ認知 — 一歩引いて自分を観測する
5. 夜の振り返り・ジャーナリング — テキストを書く習慣の価値
6. 人間関係・コミュニケーション — 言外の意味、境界線
7. 創造性・直感 — インスピーションとデータの両立（エンタメ枠）
8. クロスカルチャー — 価値観の違い、言語が思考を形作る（グローバル共感）
9. デジタル疲労・情報過多 — 入力を減らし「解析」で整理する比喩
10. 自己効力感 — 小さな行動が運命の軌道を変える（断定しすぎない）

■ 投稿フォーマット — SHORT（A〜F。premium でも **すべて出力** するが、各案は短尺のまま）
各案に 【種別】【モード:SHORT】【言語】【文字数目安】 を付ける。絵文字は 0〜2 個まで。

A. フック短文（≤280 字 / en ≤240 chars）— タイムライン停止力
B. 問いかけ — リプライ誘導（製品に誘導しすぎない）
C. ミニスレッド — 3 ツイート（1/3, 2/3, 3/3）。URL は 3/3 のみ可
D. 体験ストーリー風（架空の「ある人」）
E. シェアカード誘導（保存→ハッシュタグ、強制感なし）
F. 英語 SHORT — Culture-neutral

■ 投稿フォーマット — LONG（premium のとき **G・H 必須**）
各案に 【種別】【モード:LONG】【言語】【実文字数】 を付ける。

G. 長文エッセイ（ja **800〜1,000 字**）— 今日のテーマ軸を深掘り。X Premium 長文投稿にそのまま貼れる
H. Long-form essay（en **1,200〜1,800 chars**）— グローバル向け。同テーマの別角度

■ CTA ルール
- URL は 1 日合計 **最大 2 投稿**（SHORT と LONG 合算）。**LONG（G または H）に 1 本**、残り 1 本は SHORT のいずれか
- 含めるとき: https://get-kairos.online のみ（短縮 URL の創作禁止）
- 紹介 ref は文案に含めない（オーナーが手動で付与）
- ハッシュタグ: ja は #エンタメカイロス、en は #EntertainKAIROS（1 投稿 1 タグまで）

■ トーン
- 温かい・知的・エンタメ。煽り・恐怖マーケ・「今すぐ買え」連打は禁止
- 成功の断定（「必ず治る」「確実に儲かる」）禁止
- 比較: 都度 300×5 と 1,000 円セットの **事実比較** のみ可

■ 出力フォーマット（厳守）

## 今日のテーマ（1 行）
## 投稿モード（premium または short）
## 投稿案 — SHORT（A〜F）
## 投稿案 — LONG（G・H）※ premium のみ
（各案: 種別 / モード / 言語 / 本文 / 推奨投稿時間帯 / 実文字数または目安）

## 避けるべき表現（今日の草案に含まれていないか自己チェック 3 項目）

## オプション: 画像に載せる 1 行キャッチ（シェアカード用・18 字以内 ja / 12 words en）

■ 完了条件
- 事実にない機能・価格・キャンペーンを足さない
- 占い関連語ゼロ
- コピペですぐ投稿できる完成文のみ（解説段落は最小）
```

## Cursor（Auto）に日々書いてもらう方法

チャットで次の 1 行を送れば、上記ルールに沿った当日分をここで生成できる。

```
@docs/X_DAILY_POST_GENERATION_COMMAND.md に従い、投稿モード premium で今日の X 投稿文 A〜H を出して。Gは800〜1000字、Hは1200〜1800 chars。占い語禁止。URLは2本まで。
```

短文だけ欲しいとき:

```
@docs/X_DAILY_POST_GENERATION_COMMAND.md に従い、投稿モード short で今日の A〜F のみ。
```

**注意:** Cursor は X に自動投稿しない。コピペ投稿はオーナー作業。定期化する場合は `/loop` スキルで「毎朝この命令を実行」と別途設定が必要。
